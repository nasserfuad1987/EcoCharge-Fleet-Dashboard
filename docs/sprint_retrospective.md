# Sprint Retrospective

**Project:** EcoCharge Fleet Dashboard  
**Team:** Nasser Anwahi, Sultan Allanjawi, and Hamdan Albedwawi  
**Planned sprint:** October 26–November 8, 2026  

### What Went Well

The repository now contains both required features: a five-vehicle overview and a charging-cost calculator. Separating the data, calculation, and webpage makes the advanced version easier to understand. GitHub Actions also confirmed 25 passing tests on the advanced branch, including checks for invalid input.

### What Was Challenging

The calculation needed server-side checks because a browser form alone cannot stop every invalid request. Keeping the development branch and `main` documentation consistent was another challenge. The advanced changes were subsequently merged into `main`.

### What We Would Do Differently

We would agree on file ownership and review points earlier, then check the README and sprint documents after every major change.

### Actions for the Next Sprint

Nasser will coordinate repository updates, Sultan will check application behavior, and Hamdan will maintain testing and security checks. These responsibilities describe the intended focus for continued project maintenance.

The group used a shared GitHub account, so repository commits appear under one username rather than showing each student's separate contributions. This limits what the GitHub history can establish about individual participation.
